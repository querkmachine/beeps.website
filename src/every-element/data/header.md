---
tag: header
name: Content Header
category: Sections of a page
spec: https://html.spec.whatwg.org/multipage/sections.html#the-header-element
---

Represents the header of the nearest parent section (such as {{ eeTag("article") }} or {{ eeTag("section") }}) or the document {{ eeTag("body") }}.

When used in an article or section, it typically contains the heading for the section (see {{ eeTag("h", "`h1`–`h6`") }}) and may contain metadata like the publishing date.

When used for the document as a whole, the header usually contains the site's name or logo, the main navigation, and may include other site-wide features like search functionality.
