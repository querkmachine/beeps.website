---
tag: tbody
name: Table Body
category: Tables
spec: https://html.spec.whatwg.org/multipage/tables.html#the-tbody-element
---

Surrounds the main content of a {{ eeTag("table") }}. This will typically contain multiple {{ eeTag("tr") }} elements, each containing one or more {{ eeTag("th") }} and {{ eeTag("td") }} elements.

If a table lacks a `tbody` element, the browser will implicitly insert one.
