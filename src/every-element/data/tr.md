---
tag: tr
name: Table Row
category: Tables
spec: https://html.spec.whatwg.org/multipage/tables.html#the-tr-element
---

Container for the table cells elements, {{ eeTag("th") }} and {{ eeTag("td") }}, and delineates where each row of data begins and ends.

`tr` elements must be contained within a {{ eeTag("thead") }}, {{ eeTag("tbody") }} or {{ eeTag("tfoot") }} element.
